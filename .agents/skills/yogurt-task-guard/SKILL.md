# 작업 범위와 시간 관리

- 저장소 루트의 AGENTS.md와 대상 경로의 추가 지침을 읽는다. 이 스킬보다 실제 지침과 사용자의 명시적 요청을 우선한다.
- AGENTS.md, CLAUDE.md, README.md는 편집하지 않는다. 기존 사용자 변경도 되돌리지 않는다. 사용자가 해당 파일 편집을 명시적으로 요청했다면 그 요청 범위만 따른다.
- 요청된 결과와 수정할 파일을 정한다. 관계없는 리팩터링, 의존성 추가, 설정 변경을 포함하지 않는다.
- 시작 시각과 5분 경계를 기록한다. 필요한 검증 시간을 포함해 작업을 작게 나눈다.
- 5분을 넘길 것으로 보이면 현재 결과·남은 작업·추가 예상 시간을 설명하고 계속 진행할지 사용자 확인을 받는다. 확인 없이 5분을 넘겨 작업하지 않는다.
- 실행 가능한 범위는 먼저 완료해 검토 가능한 결과를 만든다. 시간 제한을 이유로 완료하지 않은 작업을 완료했다고 보고하지 않는다.
- 종료 전 변경 파일을 확인하고 보호 파일 수정 여부, 범위, 검증 결과와 미완료 사항을 보고한다.

이 규칙의 원본은 저장소 AGENTS.md다. 일반 작업에 별도의 승인 절차를 추가하지 않는다.
