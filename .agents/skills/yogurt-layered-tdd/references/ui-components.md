# 재사용 UI 컴포넌트 및 스타일 카탈로그

UI 화면 및 기능 구현 시 일관된 사용자 경험과 중복 방지를 위해 아래 카탈로그를 우선 재사용한다.

## 1. 재사용 컴포넌트 (`src/ui/components/`)

- **Button**: 기본 `gap-2` 간격이 적용된 버튼 컴포넌트. variant(default, outline, ghost) 및 size 지원.
- **Dialog**: 포커스 트랩과 키보드 접근성을 지원하는 모달 대화상자.
- **TextField**: 라벨, 입력 필드, 유효성 검사 오류 메시지를 통합한 입력 컴포넌트.
- **Carousel**: 반응형 가로 스크롤 슬라이더 (모바일 1장, 데스크톱 3장 넘김).
- **WeightBar**: 자산 비중 등을 시각화하는 바 차트 컴포넌트.
- **InfoTooltip**: 도움말/정보 안내 아이콘 및 호버/터치 툴팁.
- **StatGrid / SectionHeading**: (luna 작업 중) 통계 지표 그리드 및 구역 헤딩 컴포넌트.

## 2. 스타일 토큰 및 유틸리티

- **`src/ui/styles/type-scale.ts`**: 일관된 글자 크기/행간/굵기 토큰(`typeScale`) 및 간격 토큰(`spacing`).
- **`src/ui/lib/cn.ts`**: Tailwind 클래스 병합 유틸 (`clsx` + `tailwind-merge`).

## 3. 상품 상세의 선언형 구역 구성 원칙

- `src/ui/overview/product-details.ts` (luna 작업 결과로 갱신 예정):
- 각 상품(IRP, 연금저축 등)의 상세 화면은 개별 페이지마다 하드코딩하지 않고, '구역 구성'(선언형 섹션 목록 및 블록 배치) 원칙에 따라 구조화한다.

## 4. UI 구현 핵심 규칙

1. **카탈로그 우선 확인**: 새 UI를 작성하기 전에 카탈로그를 먼저 확인하고 기존 컴포넌트를 최대한 재사용한다.
2. **공통 컴포넌트 추출**: 2곳 이상에서 동일한 레이아웃이나 요소 조합 패턴이 반복되면 `src/ui/components/`로 추출한다.
3. **타이포그래피 토큰 사용**: 하드코딩된 `text-*` (예: `text-xs`, `text-sm`, `text-base` 등) 직접 사용을 지양하고 `typeScale` 토큰을 사용한다.
4. **숫자 정렬**: 금액, 수량, 수익률 등 세로로 정렬되는 숫자는 `tabular-nums` 클래스를 적용해 자릿수 흔들림을 방지한다.
5. **버튼 간격**: `Button` 내부 아이콘과 텍스트 사이는 기본 `gap-2`를 유지하고 개별 margin으로 간격을 조정하지 않는다.
